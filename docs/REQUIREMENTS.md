# 把项目需求变成工作流

KNOT 可以先读项目要求，再拆出任务，最后生成可以编辑的工作流。你可以上传老师给的作业说明、比赛项目要求或产品需求文档。

## 操作步骤

1. 新项目选择 **Upload project requirements**；已有项目打开 **AI designer**。
2. 在 **Upload project requirements** 上传 PDF、TXT 或 Markdown。PDF 需要包含可选择、复制的文字。
3. 查看 **Extracted requirement text**。这一步只是本地提取，可以核对或修正文档文字，不调用模型。
4. 在模型设置中选择提供商、填写准确的 API 模型 ID。选择 DeepSeek 可自动填入对应模型和地址。在 API key 密码框中填写凭证，点击 **Save on this device**，再点击 **Test connection** 验证连接。环境变量引用和自定义地址位于 **Advanced connection settings**；真实 key 保存在本机后端 `.env.local`，不进入工作流或浏览器持久化存储。
5. 点击 **Analyze requirements**，查看模型整理出的目标、交付物、任务、验收要求、限制和待确认信息。任务会标注对应的来源页码，可以逐项修改。
6. 确认后点击 **Generate workflow from requirements**。画布会展示工作流，你仍然可以修改积木、任务、成员分工、Agent 和连线。
7. 保存项目或导出 JSON；需要在本地执行时下载 **Export runner** 运行包。

分析和生成是两次独立的模型请求。第一次读懂要做什么，第二次把你确认的任务安排成工作流。模型请求失败会显示错误，不会换成演示模板。页面的 `Credential detected` 仅表示后端检测到凭证，不能证明 API 请求已经成功。

## 文件和编辑行为

支持 `.pdf`、`.txt`、`.md`。TXT 和 Markdown 使用 UTF-8。单个文件最多 5 MiB，PDF 最多 40 页，提取文字最多 60,000 字符；超限会被拒绝，请拆分或精简后再上传。

扫描图片 PDF 暂不支持 OCR。无法提取任何文字时会拒绝分析；部分页面没有文字时会提示这些页未被读入。加密、损坏或空白文件也会显示明确错误。

上传后可以修改提取文字；原文一旦改变，之前的分析会失效，需要重新分析，避免使用过时的任务清单。模型可能遗漏或误解要求，所以生成前需要检查任务和验收要求。文档没有提供的信息会列为待确认项，不会自动补成事实。

只上传、查看、分析或关闭弹窗都不会更改现有工作流。点击生成且成功后才替换画布，一次 Undo 可以恢复生成前的工作流。已有项目名称、成员和其它项目材料会保留。

## 保存了什么

原始 PDF 只用于本地提取，不会写入运行包。点击分析后，提取出的文字会发送到你配置的模型服务；生成工作流时也会使用这些需求文字和确认后的任务。

生成成功后，需求文字和修改后的分析会作为普通项目材料保存，路径分别为 `inputs/requirements-<标识>.txt` 和 `inputs/requirements-analysis-<标识>.json`。因此保存、刷新、导入/导出 JSON 和 ZIP 都能保留这份需求依据。取消弹窗不会把尚未采用的文件加入项目。

## 本地交付与执行方式

默认导出的是在用户电脑上调用 Codex 或 Claude 的本地工作包。Agent 可以编写并运行代码，在具备相应工具、依赖和权限时生成 PDF、离线 HTML、图表、幻灯片、Word 文档和应用源码。需求分析应保留这些最终交付要求，并安排制作、运行和验证任务；缺少依赖时应明确说明，不能仅因文件格式而把要求降级为 Markdown 或 CSV。

任务和 Output 节点的 `markdown/json/csv` 格式用于任务汇报和结构化数据。本地执行器另行收集实际项目文件，经审核后交付到 `results/project/`，因此 PDF、HTML 和图片无需配置成 Output 的汇报格式。

规划模型与本地执行方式分别配置。导出或启动时统一选择 Codex 或 Claude，可使用已安装并认证的本地 CLI 默认模型，不必为每个 Agent 填写 API 模型或凭证。仍需检查输入材料、依赖和 CLI 执行权限；不能假定外部服务已连接或应用已经部署。

高级直接 API 模式仅支持文本/CSV 文件工具，不执行 shell 或任意代码，也不直接渲染上述制品。如果明确选择该模式，分析仍须保留原始交付要求，并列出所需的外部或手动制作步骤，不能把中间内容当作已完成的最终文件；该模式的各个 Agent 仍需配置可用模型和凭证引用。
